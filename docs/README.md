# Tridingine-3DSlib

**Tridingine-3DSlib** is a library that allows you to develop games using a clean and simple API, writing practically the same code for **PC** and **Nintendo 3DS**.

Its goal is to provide a cross-platform development experience where the game maintains the same look and behavior on both platforms.

> **Status:** Early Alpha.

---

# Features

- Clean and easy-to-use API.
- Primarily designed for **C** projects with enhancements for **C++**.
- Same source code for PC and Nintendo 3DS.
- Designed to maintain consistent behavior and appearance between PC and Nintendo 3DS.
- Designed to make game development quick and simple.

# Philosophy

Tridingine-3DSlib is designed so that you can:

- Write the game once.
- Use a single API across all supported platforms.
- Build the same project for PC and Nintendo 3DS.
- Achieve consistent behavior and appearance across platforms.
